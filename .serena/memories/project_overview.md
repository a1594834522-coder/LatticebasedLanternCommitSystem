# Project Overview
- Implements Lantern, a lattice-based zero-knowledge proof system, documented in a single Jupyter notebook (`lattice-zk.ipynb`).
- Notebook blends theory explanation with interactive SageMath/Python code for constructing Module-LWE secret proofs.
- Target audience appears to be researchers/students exploring lattice-based ZKPs; material sourced from a master's project.
- No traditional source directory or package layout—work happens directly inside the notebook cells.
